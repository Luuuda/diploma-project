## Ключові нефункціональні вимоги (NFRs Matrix)

Таблиця 1 – Зведена матриця нефункціональних вимог

| Категорія | Вимога | Цільове значення |
|---|---|---|
| Продуктивність | Пропускна здатність `POST /v1/orders` | 500 RPS (сталий режим), 1000 RPS (пік, 5 хв) |
| Продуктивність | Latency прийняття замовлення | p95 ≤ 200 мс, p99 ≤ 500 мс |
| Продуктивність | Завершення Saga | p95 ≤ 3 с |
| Консистентність | Перепродаж товару | 0 випадків (10 000 запитів на 1 000 одиниць) |
| Консистентність | Дублювання платежів | 0 випадків (≥ 5 % повторних повідомлень) |
| Безпека | Автентифікація | OAuth 2.0 / OIDC, JWT (RS256), TTL ≤ 15 хв |
| Безпека | Вразливості та секрети | Trivy: 0 CRITICAL/HIGH; Gitleaks: 0 секретів |
| Надійність | Kafka | 3 брокери (KRaft), `replication.factor=3`, `min.insync.replicas=2` |
| Надійність | Відновлення PostgreSQL | RPO ≤ 5 хв, RTO ≤ 30 хв |
| Інфраструктура | Розгортання | Docker, Kubernetes (Helm), OpenTofu, GitHub Actions |
| Спостережуваність | Трасування | 100 % запитів із `trace_id` (OpenTelemetry) |
| Якість | Покриття тестами (domain, application) | ≥ 70 %, SonarQube Quality Gate: Passed |

Повна матриця (24 вимоги) наведена в [підрозділі 1.5.3](1_analysis.md).
